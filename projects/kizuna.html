The problem.

Unstable links and disappearing nodes make routing difficult. This project explores how autonomous devices can discover neighbors, share topology and adapt their forwarding decisions when conditions change.

Inside the project.

  • Protocol messages for discovery, topology sharing, routed data and emergency delivery.
  • Gradual neighbor admission and link-state routing with primary and backup paths.
  • Resilience modes and relay adaptation as links or nodes degrade.
  • A Docker validation environment and web simulator to make protocol behavior visible.

How it fits together.

01Discover neighbors
02Evaluate links
03Compute paths
04Adapt forwarding

Protocol design connects algorithms with distributed behavior. The repository separates the protocol core, reproducible experiments and visual explanation so each layer can be studied independently.

Current state.

Public protocol implementation with a simulation and validation setup. The web illustration on this portfolio is conceptual; it is not a live measurement of the protocol.
