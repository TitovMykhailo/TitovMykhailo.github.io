The problem.

A narrated video requires many coordinated editing steps. This repository organizes them into a configurable pipeline with intermediate files and editing profiles.

Inside the project.

  • Pipeline stages for transcription, cut planning and synchronized captions.
  • Media and audio-library indexing with style-profile configuration.
  • DaVinci Resolve integration scripts and an OTIO fallback path.
  • Storyboard, timing and timeline-validation references.

How it fits together.

01Voiceover
02Transcript + plan
03Media + captions
04Resolve timeline

Creative automation benefits from visible intermediate stages so an editor can inspect and revise the result instead of treating the pipeline as a black box.

Current state.

Public repository with configurable editing stages and DaVinci Resolve integration. Full operation depends on local tools, media and configuration; the workflow has not been executed as part of creating this portfolio.
