The problem.

Study groups need a way to keep discussion, tasks and learning resources connected. The application combines them in one shared group workspace.

Inside the project.

  • Group and member management with roles.
  • Task CRUD, deadlines and links to shared resources.
  • Realtime chat, typing events and online status over WebSocket.
  • JWT and Google OAuth2, plus documented Google Cloud deployment configuration.

How it fits together.

01React workspace
02REST / WebSocket
03Spring Boot
04PostgreSQL + GCS

This project combines synchronous API requests with realtime events and connects authorization, file storage and collaborative interface state.

Current state.

Public source project with startup and deployment instructions. This portfolio links to the code; it does not claim that a production deployment is currently online.
