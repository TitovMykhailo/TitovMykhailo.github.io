Job Hunter Agent

A Python pipeline that collects job listings, filters low-signal posts, scores relevance with Azure OpenAI and logs results to Google Sheets.

The problem.

A job feed can contain duplicate listings, unsuitable seniority levels and unrelated posts. The pipeline applies filtering before AI-based scoring to produce a more relevant list.

Inside the project.

  • Collection adapters for multiple job sources.
  • Prefiltering for low-signal and seniority-mismatched posts.
  • Azure OpenAI relevance scoring on a 0–10 scale.
  • Deduplication through a processed-job log and separate Google Sheets views.

How it fits together.

01Collect listings
02Filter duplicates
03Score relevance
04Log to Sheets

A useful AI workflow needs deterministic filtering and traceable outputs around the model. The repository separates collection, scoring and logging into distinct modules.

Current state.

Public Python source project. Live operation depends on configured API access and source availability. Gmail reply checking is documented as disabled; no autonomous application submission is claimed here.
