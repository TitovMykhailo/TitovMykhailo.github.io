A Python pipeline that collects job listings, filters low-signal posts, scores relevance with Azure OpenAI and logs results to Google Sheets.

The problem

Job feeds are full of duplicates, “for hire” posts, discussions and senior-only roles. Reading all of it by hand doesn’t scale.

What I built

  • Collectors for Profesia.sk, Worki.sk, LinkedIn, Jobs.sk and Reddit.
  • Deterministic pre-filters for candidate posts, general discussions and strong seniority mismatches — before any model call.
  • Azure OpenAI scores each remaining listing from 0 to 10; listings scoring 7 or more go to the shortlist.
  • Two Google Sheets views (shortlist and full log), deduplication via a processed-jobs file, and a cron schedule every six hours.

How it works

  1. 1Collect listings
  2. 2Filter low-signal posts
  3. 3Score with Azure OpenAI
  4. 4Write to Google Sheets

Results

Public Python project. It runs on a schedule with configured API keys; Gmail reply checking is currently disabled, and it never applies to jobs on its own.

What I learned

Cheap deterministic filters in front of the model cut both cost and noise — the model only judges listings that could plausibly fit.
