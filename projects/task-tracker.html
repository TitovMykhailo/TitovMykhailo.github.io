The problem.

Tasks, time entries and project progress are easier to understand when they share one workspace. This application brings those workflows together behind a REST API.

Inside the project.

  • JWT authentication and CRUD APIs for projects, tasks, reminders and widgets.
  • A React interface with a dashboard, calendar, analytics and project boards.
  • Active time-tracking sessions and project-progress views.
  • A drag-and-resize widget grid, draft/publish workflow and Docker Compose setup.

How it fits together.

01React interface
02REST + JWT
03Spring services
04PostgreSQL

A full-stack project brings together data modeling, authentication, API boundaries and interface state. This project also explores extensibility through configurable widgets.

Current state.

Public source project. The repository documents backend integration tests and local startup instructions. The Generate with AI feature is a UI-only, rule-based mock; stored Java logic is not executed on the server.
