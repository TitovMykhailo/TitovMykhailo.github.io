The problem.

Information in pathology reports and tumour diagrams needs to be converted into consistent registry fields. The challenge is to help a clinician review proposed values alongside the original documents.

Inside the project.

  • A document-to-structured-record workflow for the Masaryk Memorial Cancer Institute challenge.
  • Source documents displayed alongside proposed extracted values.
  • A review step for corrections and conflicting information before confirmation.
  • A production architecture intended for hospital-controlled servers and local processing.

How it fits together.

01Input documents
02Extract proposals
03Clinician review
04Registry export

In document workflows, useful automation needs a clear review surface and a visible path back to the source. The interface illustration here uses generic placeholder fields.

Current state.

Team hackathon prototype from RAKATHON in Brno. Individual contribution details are not yet documented here. Production deployment and live registry integration are separate validation steps. No patient data is displayed on this portfolio.
